# Binary Tree Generation — v.02

Вторая версия проекта по генерации бинарного дерева.

В этой версии реализованы два подхода к построению дерева — рекурсивный и итеративный. Также добавлены автоматизированное тестирование и измерение времени выполнения алгоритмов.

## Что добавлено

* рекурсивная генерация бинарного дерева;
* итеративная генерация бинарного дерева;
* возможность задавать параметры генерации;
* автоматизированные тесты;
* проверка обычных, граничных и некорректных входных данных;
* измерение времени выполнения алгоритмов;
* сохранение результатов измерений;
* визуализация результатов.

## Сравнение алгоритмов

В проекте реализованы две функции:

`gen_bin_tree_recursive()` — рекурсивный вариант построения бинарного дерева.

`gen_bin_tree()` — итеративный вариант построения бинарного дерева.

Для оценки производительности используется стандартный модуль Python `timeit`.

Количество итераций постепенно увеличивается, после чего результаты замеров используются для сравнения двух реализаций.

## Тестирование

Для проверки корректности алгоритмов используются автоматизированные тесты.

Проверяются:

* корректные входные данные;
* граничные значения;
* некорректные параметры;
* рекурсивная реализация;
* итеративная реализация.

Запуск тестов:

```bash
pytest
```

## Бенчмаркинг

Измерение времени выполнения выполняется с помощью стандартного модуля Python `timeit`.

Результаты замеров сохраняются в:

```text
record.txt
```

На основе полученных данных строится график сравнения рекурсивной и итеративной реализаций.

![Сравнение производительности](Figure.png)

График позволяет сравнить время выполнения двух подходов при увеличении количества итераций.

## Структура

```text
v.02/
├── main.py
├── test_get_bin_tree.py
├── record.txt
├── Figure.png
├── pyproject.toml
└── poetry.lock
```

`main.py` — реализация алгоритмов генерации бинарного дерева и проведение замеров производительности.

`test_get_bin_tree.py` — автоматизированные тесты.

`Figure.png` — графическое представление результатов.

`poetry.lock` — зафиксированные версии зависимостей.

* Python

## Запуск

Установка зависимостей:

```bash
poetry install
```

Запуск программы:

```bash
python main.py
```

Запуск тестов:

```bash
pytest
```

## История проекта

Проект первоначально разрабатывался в среде **Replit**, после чего исходный код был перенесён в GitHub.

`v.02` является продолжением `v.01`: рекурсивная реализация была дополнена итеративным вариантом, после чего оба подхода были протестированы и сравнены по времени выполнения.
