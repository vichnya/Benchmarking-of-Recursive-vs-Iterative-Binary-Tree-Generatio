# Benchmarking Recursive vs Iterative Binary Tree Generation

Учебный проект на Python, посвящённый сравнению рекурсивного и итеративного подходов к генерации бинарного дерева.

Проект развивался в несколько этапов: от базовой рекурсивной реализации до сравнения двух вариантов алгоритма с автоматизированным тестированием и измерением времени выполнения.

## Цель

Исследовать два подхода к построению бинарного дерева:

* рекурсивный;
* итеративный.

Для сравнения реализаций используются автоматизированные тесты и замеры времени выполнения.

## Версии проекта

### v.01 — рекурсивная реализация

Первая версия содержит:

* рекурсивную генерацию бинарного дерева;
* базовую проверку работы алгоритма;
* автоматизированные тесты.

### v.02 — сравнение подходов

Во второй версии добавлены:

* рекурсивная реализация с параметрами;
* итеративная реализация;
* автоматизированное тестирование;
* проверка граничных и некорректных значений;
* измерение времени выполнения с помощью `timeit`;
* сохранение результатов измерений;
* визуализация результатов.

## Тестирование

Для проверки корректности реализации используются автоматизированные тесты.

Проверяются:

* обычные входные данные;
* граничные значения;
* некорректные параметры;
* работа рекурсивной реализации;
* работа итеративной реализации.

## Бенчмаркинг

В `v.02` реализовано сравнение производительности двух подходов.

Для измерения времени выполнения используется стандартный модуль Python `timeit`.

Результаты измерений сохраняются в `record.txt` и используются для построения графика.

## История проекта

Проект первоначально разрабатывался в среде **Replit**, после чего исходный код был перенесён в GitHub.

Работа выполнялась поэтапно: сначала была реализована рекурсивная версия алгоритма, затем добавлена итеративная реализация и проведено сравнение производительности.

## Результат

Проект позволяет на практике сравнить два способа решения одной задачи и оценить их поведение при увеличении объёма вычислений.
