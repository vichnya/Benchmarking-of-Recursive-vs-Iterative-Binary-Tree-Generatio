# Binary Tree Generation — v.01

Первая версия проекта по генерации бинарного дерева.

В этой версии реализован рекурсивный алгоритм построения бинарного дерева и добавлены автоматизированные тесты для проверки его работы.

## Возможности

* рекурсивная генерация бинарного дерева;
* проверка корректности работы функции;
* автоматизированное тестирование.

## Структура

```text id="r3y4mp"
v.01/
├── main.py
├── test_get_bin_tree.py
└── ...
```

`main.py` — реализация алгоритма генерации бинарного дерева.

`test_get_bin_tree.py` — автоматизированные тесты.

## Тестирование

Для проверки реализации используются тесты.

Запуск:

```bash
pytest
```

## Технологии

* Python
* pytest
* Poetry

## История проекта

Проект разрабатывался в среде **Replit**, после чего исходный код был перенесён в GitHub.

`v.01` — первый этап проекта. В следующей версии (`v.02`) рекурсивная реализация была дополнена итеративным подходом, тестированием различных случаев и сравнением производительности.
